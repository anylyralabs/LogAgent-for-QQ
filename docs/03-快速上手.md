# LogAgent 快速上手

> 2026-10-15 ｜ M0-M5 全里程碑已落地 ｜ .NET 10 LTS ｜ 构建 0 错误 ｜ 71/71 测试通过

## 1. 从源码运行（开发）

```bash
cd E:/logagent-for-qq
dotnet run --project src/LogAgent.App        # Windows 桌面
dotnet run --project src/LogAgent.Headless   # 无头 CLI（也可跑 Linux）
```

## 2. 发布

```bash
# Windows 单文件免安装（self-contained）
dotnet publish src/LogAgent.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish/win-x64

# Linux 无头（服务器 systemd/Docker）
dotnet publish src/LogAgent.Headless -c Release -r linux-x64 -o publish/linux-x64
```

数据与配置都在用户目录：Windows `%AppData%\LogAgent\`，Linux `~/.config/LogAgent/`（config.json、data/logagent.db、data/knowledge.db、sandbox/）。

## 3. 首次配置（五步联调）

1. **配模型**：桌面应用 →「模型路由」→ 新增 Provider（OpenAI 兼容接口：名称/Endpoint/ApiKey/ChatModel）→ 测试选中连接 → 保存。规则链按任务类型指定优先级（聊天/日志分析/深度推理/摘要/Embedding 各一条链）。
2. **装 NapCat**：下载 NapCat Shell 版解压到任意目录 →「NapCat 管理」页填目录 → 启动 NapCat。
3. **扫码**：同页点「获取/刷新二维码」（Token 自动从 webui.json 读取）→ 手机 QQ 扫码 → 状态变「已在线」。之后可用快速登录免扫码。
4. **接通**：NapCat WebUI（127.0.0.1:6099）→ 网络配置 → 新建反向 WebSocket Client → URL 填 `ws://127.0.0.1:6701/onebot/v11/ws`（与 Bot 服务页端口一致，Token 留空或填配置值）。
5. **开跑**：Bot 服务页点「启动服务」→ 群里 `@机器人` 说话测试。

## 4. 群内命令速查

| 命令 | 效果 |
|---|---|
| `@机器人 你好` | 带群上下文 + RAG 知识的对话（可设关键词免@） |
| `@机器人 分析日志` + 换行粘贴日志 | 根因分析报告（分段发送） |
| `记住：<知识>` | 学习入库（候选，审核后生效） |
| `学习 https://…` | 抓网页提炼入库（候选） |
| `新话题` / `换个话题` / `/new` | 立即切段会话 |

## 5. 管理后台页面

仪表盘（路由计量/会话/知识统计）｜模型路由（provider+规则+熔断状态）｜NapCat 管理（扫码/快速登录/服务启停）｜知识库（候选审核）｜记忆浏览器（问答对）｜会话管理（切段/L1摘要/**导出训练数据**）｜沙箱（命令审计/白名单）｜设置（触发规则/会话参数）。

## 6. 训练数据导出

- UI：会话管理 →「导出训练数据」→ 选格式（OpenAI Chat / ShareGPT / Alpaca / DPO 对）；
- CLI：`LogAgent.Headless export <chat|sharegpt|alpaca|dpo> <out.jsonl>`；
- 导出**强制脱敏**（手机号/IP/密钥/带凭据URL/邮箱→占位符），同目录写入 `export_audit.jsonl` 审计；
- DPO 对自动从"同问题多次回答"（用户纠正重问）构造：早回复=rejected，晚回复=chosen。

## 7. 已知边界（后续迭代）

- 官方 QQ 机器人适配器已实现（token/网关/心跳/被动回复全链路），需开放平台凭证真机联调；

- 会话质量标签（adopted/corrected）目前由导出侧按重复提问推断，群内点赞/纠正打标待接 UI。

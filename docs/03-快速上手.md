# LogAgent 快速上手

> 2026-10-19 ｜ M0-M5 全里程碑已落地 ｜ .NET 10 LTS ｜ Windows 桌面 + Linux 无头双形态

## 1. 从源码运行（开发）

```bash
dotnet run --project src/LogAgent.App        # Windows 桌面（WPF，全功能）
dotnet run --project src/LogAgent.Desktop    # 跨平台桌面（Avalonia，Windows / Linux）
dotnet run --project src/LogAgent.Headless   # 无头 CLI（Windows / Linux 均可）
```

## 2. 发布

```bash
# Windows 单文件免安装（self-contained）
dotnet publish src/LogAgent.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish/win-x64

# Linux 无头（服务器 systemd/Docker）
dotnet publish src/LogAgent.Headless -c Release -r linux-x64 --self-contained -p:PublishSingleFile=true -o publish/linux-x64
```

Linux 上还提供环境自检与端到端自检（不联网）：

```bash
./publish/linux-x64/LogAgent.Headless doctor     # 配置 / 目录权限 / shell / 白名单 / MCP / 端口
./publish/linux-x64/LogAgent.Headless selftest   # 装配 → 沙箱 → 本机对话 → 假模型端点
./publish/linux-x64/LogAgent.Headless serve      # 常驻，SIGTERM 时切段会话后退出
```

部署细节（systemd / Docker / NapCat 反向 WS）见 [Linux 部署](05-Linux部署.md)。

数据与配置都在用户目录：Windows `%AppData%\LogAgent\`，Linux `~/.config/LogAgent/`（config.json、data/logagent.db、data/knowledge.db、sandbox/、skills/）。
容器或多实例场景可用环境变量 `LOGAGENT_CONFIG_DIR` 指定独立目录。

## 3. 首次配置（五步联调）

1. **配模型**：桌面应用 →「模型路由」→ 新增 Provider（OpenAI 兼容接口：名称/Endpoint/ApiKey/ChatModel）→ 测试选中连接 → 保存。规则链按任务类型指定优先级（聊天/日志分析/深度推理/摘要/Embedding 各一条链）。
2. **接入 QQ（推荐官方 Bot，优先支持）**：打开「官方 Bot」页 →「显示二维码」→ 手机 QQ 扫码绑定 → 凭证自动填入并保存 → 勾选「启用」「Markdown」→「连接」。
   - Markdown 需开放平台权限；未开通时会自动回退纯文本。
   - 群聊主动消息需群主在 QQ 中开启「机器人主动在群聊内发言」。
3. **备用 NapCat（可选，可与官方 Bot 并行）**：下载 NapCat Shell 版解压到任意目录 →「NapCat 管理」页填目录 → 启动 NapCat → 手机 QQ 扫码登录。
4. **接通 NapCat**：NapCat WebUI（127.0.0.1:6099）→ 网络配置 → 新建反向 WebSocket Client → URL 填 `ws://127.0.0.1:6701/onebot/v11/ws`（与 Bot 服务页端口一致，Token 留空或填配置值）。
5. **开跑**：在「官方 Bot」/「NapCat 管理」页勾选启用需要的频道（官方 Bot 优先级 100，OneBot 50）；
   勾选「启动后自动连接」或点对应页面的「启动/连接」→ 群里 `@机器人` 说话测试。

## 4. 群内命令速查

| 命令 | 效果 |
|---|---|
| `@机器人 你好` | 带群上下文 + RAG 知识的对话（可设关键词免@） |
| `@机器人 分析日志` + 换行粘贴日志 | 根因分析报告（分段发送） |
| `记住：<知识>` | 学习入库（候选，审核后生效） |
| `学习 https://…` | 抓网页提炼入库（候选） |
| `新话题` / `换个话题` / `/new` | 立即切段会话 |

## 5. 管理后台页面

仪表盘（路由计量/会话/知识统计）｜模型路由（provider+规则+熔断状态）｜NapCat 管理（扫码/快速登录/服务启停）｜知识库（候选审核）｜记忆浏览器（问答对）｜会话管理（切段/L1摘要/**导出训练数据**）｜沙箱（命令审计/白名单）｜设置（触发规则/会话参数）。

## 6. 训练数据导出

- UI：会话管理 →「导出训练数据」→ 选格式（OpenAI Chat / ShareGPT / Alpaca / DPO 对）；
- CLI：`LogAgent.Headless export <chat|sharegpt|alpaca|dpo> <out.jsonl>`；
- 导出**强制脱敏**（手机号/IP/密钥/带凭据URL/邮箱→占位符），同目录写入 `export_audit.jsonl` 审计；
- DPO 对自动从"同问题多次回答"（用户纠正重问）构造：早回复=rejected，晚回复=chosen。

## 7. 已知边界（后续迭代）

- 官方 QQ 机器人适配器已实现（token/网关/心跳/被动回复全链路），需开放平台凭证真机联调；
- NapCat 本机进程托管：Windows 选 `.bat`/`.exe`，Linux 可选 `.sh` 脚本或直接用 NapCat Docker；
- Linux 沙箱默认命令集为 POSIX（grep/sed/awk/find…）；从 Windows 迁移的旧配置白名单需要 `LogAgent.Headless config repair-sandbox` 重置；
- 知识库关键词检索为 LIKE 实现（万条级毫秒级），FTS5/sqlite-vec 向量索引优化待规模化需求；
- 会话质量标签（adopted/corrected）目前由导出侧按重复提问推断，群内点赞/纠正打标待接 UI。

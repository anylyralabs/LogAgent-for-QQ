# 安装包模式与首次启动体验设计

> 2026-10-15 ｜ 调研主流桌面应用分发与首启模式，并落地到 LogAgent

## 1. 业界安装包模式调研结论

| 模式 | 代表 | 适用 | LogAgent 采纳 |
|---|---|---|---|
| **便携版文件夹/zip** | VS Code portable、开发者工具 | 免安装、U盘、绿色党 | ✅ 已有（publish/win-x64 整目录） |
| **Inno Setup / NSIS EXE 安装器** | 消费软件主流（electron-builder 默认 NSIS） | 单文件安装器、快捷方式、卸载注册、per-user 免管理员 | ✅ 采用 Inno Setup（tools/installer.iss） |
| **MSIX** | 微软商店/企业 MDM | 需签名证书、商店分发 | ❌ 暂不需要（无签名证书，非商店渠道） |
| **MSI** | 企业 GPO/SCCM 部署 | 集中运维 | ❌ 非目标场景 |
| **Squirrel/Velopack 自动更新** | Discord/Slack | 需要自动更新体系 | ⏳ M6 候选（Velopack 是 Squirrel 现代继任者，原生支持 .NET） |

**决策**：便携版 + Inno Setup 双通道。理由：免费开源、脚本化可进 CI、per-user 安装免管理员、中文语言包现成、单文件 LZMA 压缩安装器；企业 MSI 需求出现时再用 WiX 包一层。

安装细节：`%LocalAppData%\Programs\LogAgent`（per-user），可选桌面快捷方式，卸载注册到 HKCU，**卸载保留用户数据**（`%AppData%\LogAgent` 的配置/会话库/知识库）。

## 2. 首次启动体验调研结论

参考对象（同类 AI 桌面客户端的共性模式）：

- **WorkBuddy / DeepSeek Harness / ToClaw**：安装完成 → 首启进入**图形化初始化向导**（账号/模型配置 → 权限授权 → 绑定通讯工具）→ 进主界面；全程无命令行；
- **AionClaw**：六步向导含环境自检 + 依赖静默安装 + 扫码绑定通讯工具，失败项高亮 + 一键修复；
- **VS Code/Obsidian**：无向导、开箱即用 + 渐进式功能引导（适合工具型，LogAgent 需要初始配置，向导更合适）。

共性设计原则：**步骤少（≤3）、每步可跳过、即时反馈（测试连接按钮）、图形化零命令行、扫码绑定放在向导外但给出明确指引**。

## 3. LogAgent 落地

### 首启向导（已实现）
- 触发条件：`AppConfig.WizardCompleted == false`（配置文件不存在时天然为 false）；
- **Step 1 欢迎**：功能概览 + 两步初始化说明；
- **Step 2 模型通道**：表单（名称/Endpoint/ApiKey/ChatModel）+「测试连接」即时反馈，通过后自动保存并把该 provider 设为所有任务类型的首选链；可跳过；
- **Step 3 NapCat 指引**：启动/扫码/反向 WS 地址展示；点「完成」写 `WizardCompleted=true`，进入主界面；
- 向导期间侧边栏禁用，防止未配置就乱点。

### 安装器（tools/installer.iss）
编译产出 `LogAgent-Setup-x64-<version>.exe`：
```
1. dotnet publish src/LogAgent.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish/win-x64
2. Inno Setup Compiler 打开 tools/installer.iss → 编译
```
含：中文安装界面、桌面快捷方式选项、完成页"立即启动"、卸载保留数据。
